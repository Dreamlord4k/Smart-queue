# Стартовый промпт для Codex (Astra)

Скопируй в первое сообщение новой сессии Codex в корне репозитория:

---

Ты — исполнитель в этом репозитории. Прочитай по порядку: AGENTS.md → PRODUCT.md → PLAN.md → TASKS.md.

Прежде чем менять любые файлы:
1. Если что-то в PRODUCT.md/PLAN.md/TASKS.md кажется неполным, противоречивым или недостаточным для реализации задачи T-001 — задай мне до 5 уточняющих вопросов. Не додумывай и не выбирай самостоятельно то, что явно требует моего решения.
2. Если вопросов нет — начни с задачи T-001 из TASKS.md, ровно в её `Разрешённые файлы`, и ни с чем другим.
3. Перед BUILD убедись, что понял: почему двигать можно только свою запись в очереди (см. неснимаемые правила в AGENTS.md) и почему это важно — если это ограничение непонятно, спроси, а не молчи и не игнорируй.
4. Сделай маленький diff под одну задачу, запусти тесты из раздела «Проверки» в TASKS.md, покажи результат.
5. Когда тесты прошли — закоммить в ветку `task/T-001` и открыть Pull Request через доступную GitHub-интеграцию (см. правило в AGENTS.md). Не мёржи сам.
6. Создай файл попытки `docs/agent/tasks/T-001/<UTC>_backend_a01.md` по шаблону из `docs/agent/tasks/T-001/README_TEMPLATE.md`.
7. Не трогай TASKS.md сам — только я (или основной агент) отмечаю статус после проверки.

Точную схему данных, полный список API и рекомендации по стеку смотри в `docs/TECH_SPEC.md`, если потребуется — не переспрашивай то, что там уже написано.
