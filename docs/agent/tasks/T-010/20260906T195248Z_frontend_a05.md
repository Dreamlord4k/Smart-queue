### Неснимаемое правило self-reorder
Перетаскивается только запись, у которой `student_id` совпадает с `sub` access JWT, `status=waiting`, `locked=false` и `session.frozen=false`. Чужие записи никогда не становятся источником перемещения. Серверная проверка остаётся обязательной, потому что клиентский UI можно подменить; это защищает чужой порядок и зафиксированные места.
