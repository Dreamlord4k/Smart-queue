### ШАГ 1. Токены (theme.css — у нас приняты CSS-переменные, tokens.ts не заводил)
Роли M3: primary #FF6F5E / onPrimary #FFFFFF / primaryContainer #FFDAD3 /
secondary #3E7C99 / secondaryContainer #D3E7F0 / surface #FFFBFA /
surfaceVariant #F1E4E0 (+surfaceContainer) / onSurface #201A18 /
outline #857370; error выведен из палитры по M3 (светлая #B3261E, тёмная #F2B8B5 —
коралл на белом не дотягивал по контрасту для мелкого текста).
Тёмная: та же роль-система, тёплая поверхность #171210 (не чёрный); включается
[data-theme="dark"], без выбора — prefers-color-scheme теми же тонами.
Форма: чипы 12px → карточки/модалки 28px; поля и главные кнопки — pill 9999px.
Типографика Manrope: display 32/800, headline 22/700, body 16/400, label 13/700.
Движение: --ease-spring cubic-bezier(0.34,1.4,0.64,1), один момент — появление
карточек rise-spring 450ms (+prefers-reduced-motion).
