### Решения
- Группы: эндпоинта GET /groups ещё нет (scope T-008), поэтому студент вводит ID группы (UUID) текстом; поле показано только при роли student, преподавателю group_id не отправляется (иначе backend вернёт 422).
- Роль для редиректа читается из payload access-токена (GET /auth/me нет); фолбэк — student.
- Редирект по умолчанию через window.location + проп onSuccess для тестов/будущего роутера.
- Чистые функции loginUser/registerUser принимают fetchImpl — тестируются без testing-library (её нет в зависимостях).
