# backend/AGENTS.md

- `alpha = 0.3` для EMA — константа, вынесена в конфиг (`backend/config.py`), не хардкодить в нескольких местах.
- ETA-пересчёт запускать только при изменении состояния активной очереди (done/skip/absence/reorder/lock/freeze/добавление участника) — никогда по таймеру, кроме фоновой рассылки мягких уведомлений (см. PLAN.md, Этап 5). `absent` исключается из активной очереди, но запись и `absence_reason` не удаляются.
- Любой эндпоинт, меняющий `position`, обязан проверить: (1) запись принадлежит текущему пользователю, (2) целевое место не `locked`, (3) `session.frozen != true`.
- `lock_reason` и `absence_reason` — независимые необязательные тексты; отказ меняет только запись текущей сессии и не может менять состояние других очередей студента.
- Не писать напрямую в `TASKS.md` из кода/скриптов — это файл человека и основного агента.
